## 7. Currently broken / degraded user flows (reproduced)

1. **Live Gemini mode is broken (R-01).** With a key configured, auto mode attempts the
   model call and fails; every run is labelled `offline-fallback`. Functionality survives,
   but the advertised Gemini mode does not work end-to-end. Reproduced via
   `npm run smoke:gemini` (exit 1) and the run-mode rows in §8.
2. **`next dev` cannot run twice for this project, whatever the port (R-07).** The e2e
   webServer (port 3100) is rejected while any other `next dev` of the same project is up.
   Reproduced (first Playwright attempt, exit 1, "Another next dev server is already
   running").
3. No other user flow failed during this review: signup, login, logout, inbox/counts,
   case analysis, multi-turn follow-up, tickets, knowledge, audit, settings, isolation,
   mobile layout, Docker startup, migrations, seed and persistence all passed.
